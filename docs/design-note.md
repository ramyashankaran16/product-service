# Design Note — Product Service (Task 1)

**Stack:** Python 3.12, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL 16 (SQLite in-memory for tests only), pytest.

## 1. Endpoints

| Method | Path | Success | Errors |
|---|---|---|---|
| POST | /api/v1/products | 201 + Location | 400, 409 |
| GET | /api/v1/products/{id} | 200 | 400 (bad UUID), 404 |
| GET | /api/v1/products | 200 | 400 |
| PUT | /api/v1/products/{id} | 200 | 400, 404, 409 |
| PATCH | /api/v1/products/{id} | 200 | 400, 404, 409 |
| DELETE | /api/v1/products/{id} | 204 | 400, 404 |
| GET | /health | 200 (503 if DB down) | — |

Any other method on these paths → 405. List: `page` starts at **1**; `size` default 10, max 100; filters `category`, `status`, `minPrice`, `maxPrice`; `sort=<field>,<asc|desc>`, default `createdAt,desc`. Response: `{items, page, size, totalItems, totalPages}`.

## 2. Data model (`products` table)

| Column | DB type | Constraint |
|---|---|---|
| id | UUID | PK, generated by server |
| name | VARCHAR(100) | NOT NULL, unique index on `lower(name)` |
| description | VARCHAR(500) | nullable |
| price | NUMERIC(10,2) | NOT NULL, CHECK > 0 |
| quantity | INTEGER | NOT NULL, CHECK >= 0 |
| category | VARCHAR(50) | NOT NULL, indexed |
| status | VARCHAR(10) | NOT NULL, default ACTIVE, CHECK IN (ACTIVE, INACTIVE), indexed |
| created_at | TIMESTAMPTZ | NOT NULL, set on insert |
| updated_at | TIMESTAMPTZ | NOT NULL, set on insert and every update |

## 3. Validation rules

- name: required string, trimmed, 2–100 chars, unique ignoring case → 409 if taken
- description: optional string, trimmed, ≤ 500 chars, blank → null
- price: required number (not string), > 0, ≤ 2 decimal places
- quantity: required integer (not string/float), ≥ 0
- category: required string, trimmed, 2–50 chars
- status: ACTIVE | INACTIVE, default ACTIVE
- id / createdAt / updatedAt / unknown fields in body → 400
- malformed JSON → 400; malformed UUID in path → 400; unknown id → 404
- PATCH: at least one field; null only allowed for description
- list: minPrice ≤ maxPrice, size 1–100, page ≥ 1, valid sort field and direction

Validation of shape/types happens in DTOs (Pydantic); business rules (uniqueness, price range, sort, empty patch) live in the service layer. All errors share one JSON format via global handlers.

## 4. Folder structure

```
app/api (controllers) → app/services (business rules) → app/repositories (queries) → app/models (entities)
app/schemas (DTOs), app/exceptions (errors + handlers), app/core (config, logging, middleware), app/db
alembic/versions (migrations), tests/unit, tests/integration, docs, postman
```
